

# SZIKRA
40mm disc, personal assistant.

Black body, colorful soul.
8 colors: ROSE, ICE, GOLD, FOREST, CRIMSON, AMETHYST, SUNSET.

4 months development in Dunavarsány, Hungary.
Made for blind people, but good for everyone.
Work, leisure, sport.
Less screen.

### Specification
- 40mm disc
- 3 tactile dots
- LED ring
- OV5640 camera
- ESP32
- 400mAh battery
- Platform strap with 4 straps, unique solution

### Usage
- Work
- Leisure
- Sport
- Running with water drops, NIGHT version glows strong
